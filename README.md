# Greeny — releases

Installers of Greeny, accounting for clinics and salons with voice control.

Open the newest release under **Releases** and download:

- `Greeny-Setup-<version>.exe` — the program for the Windows computer. Run it: it installs over the old version, the data stays.
- `Greeny-<version>.apk` — the phone app for Android. Open it on the phone and install it over the old one.

Windows may warn that the publisher is unknown: «More info» → «Run anyway».

---

# Greeny — обновления

Установщики Greeny. Откройте последний релиз в разделе **Releases** и скачайте:

- `Greeny-Setup-<версия>.exe` — программа для компьютера с Windows. Запустите: она встанет поверх прежней версии, данные сохранятся.
- `Greeny-<версия>.apk` — приложение для телефона на Android. Откройте его на телефоне и установите поверх прежнего.

Если Windows предупредит о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».
